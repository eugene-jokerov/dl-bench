# bench.js — замер скорости скачивания URL

Консольный скрипт на Node.js без внешних зависимостей. Делает к указанному адресу
10 последовательных запросов, дожидается полного чтения тела каждого ответа и
считает среднее время запроса, суммарный объём скачанных данных и скорость
скачивания.

## Требования

- Node.js 18 или новее (проверено на Node 24).
- Внешние пакеты не нужны — только стандартная библиотека Node.

## Запуск

```bash
node bench.js <url>
```

Пример:

```bash
node bench.js https://proof.ovh.net/files/100Mb.dat
```

### Опции

| Опция             | Описание                                                | По умолчанию |
| ----------------- | ------------------------------------------------------- | ------------ |
| `--runs=<n>`      | Количество последовательных запросов                    | `10`         |
| `--no-cache`      | Отправлять заголовки anti-cache (включено по умолчанию) | включено     |
| `-h`, `--help`    | Показать справку                                        | —            |

Примеры:

```bash
node bench.js https://proof.ovh.net/files/10Mb.dat
node bench.js https://proof.ovh.net/files/10Mb.dat --runs=5
```

## Что делает скрипт

- Проверяет URL (поддерживаются только `http://` и `https://`).
- Выполняет заданное число GET-запросов **строго последовательно**: следующий
  запрос стартует только после полного получения ответа на предыдущий.
- Каждый запрос читает тело ответа до конца и считает его размер в байтах.
- Отключает кэш заголовками `Cache-Control: no-cache` и `Pragma: no-cache`,
  чтобы измерялась сеть, а не локальный кэш.
- Следует за HTTP-редиректами (до 5 переходов).
- Таймаут одного запроса — 60 секунд.
- Завершается с ненулевым кодом, если были ошибки или ответы с не-2xx статусом.

## Единицы измерения

- **Время** — миллисекунды (ms) на запрос, и секунды (s) для суммарного времени.
- **Объём** — байты и **MiB** (мебибайты: 1 MiB = 1024 × 1024 = 1 048 576 байт).
- **Скорость** — **MiB/s** (мебибайты в секунду). В скобках дополнительно
  приводится **Mbit/s** (мегабиты в секунду, 1 Mbit = 1 000 000 бит).

Скорость считается как общий объём скачанных данных, делённый на суммарное
время всех успешных запросов. Поскольку запросы последовательные, эта величина
совпадает с «объём среднего запроса / среднее время запроса».

## Примеры файлов для теста

Это ссылки на файлы 10 МБ и 100 МБ (не сами файлы). Ресурсы сторонние, их
доступность и скорость могут меняться.

**10 МБ:**

- <https://proof.ovh.net/files/10Mb.dat>
- <https://ipv4.download.thinkbroadband.com/10MB.zip>
- <https://speed.hetzner.de/10MB.bin>
- <http://speedtest.tele2.net/10MB.zip>

**100 МБ:**

- <https://proof.ovh.net/files/100Mb.dat>
- <https://ipv4.download.thinkbroadband.com/100MB.zip>
- <https://speed.hetzner.de/100MB.bin>
- <http://speedtest.tele2.net/100MB.zip>

Готовые команды:

```bash
# 10 МБ
node bench.js https://proof.ovh.net/files/10Mb.dat

# 100 МБ
node bench.js https://proof.ovh.net/files/100Mb.dat
```

> Учтите: ресурс скачивается 10 раз подряд без кэша. Для файла 100 МБ это
> означает около 1 ГБ трафика за один прогон. Уменьшить число запросов можно
> опцией `--runs=<n>`.
